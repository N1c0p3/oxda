# Backlog MVP priorizado

## Sprint 1: Base de plataforma
- Autenticación y autorización por roles
- Catálogos base (usuarios, áreas, productos, almacenes)
- Registro de lotes
- Estructura de auditoría (created_by, timestamps)

## Sprint 2: Operación de planta
- Plan de producción por turno
- Órdenes de proceso
- Captura operativa por trabajador
- Cálculo de productividad y merma

## Sprint 3: Inventario y trazabilidad
- Movimientos de inventario
- Kardex por producto/lote
- Existencia por almacén
- Trazabilidad completa de lote

## Sprint 4: Ventas y CRM
- Clientes y contactos
- Pipeline de oportunidades
- Pedidos de venta
- Estado de cumplimiento de pedido

## Sprint 5: Logística
- Programación de envíos
- Asignación de ruta/unidad/operador
- Evidencia de entrega
- Devoluciones

## Sprint 6: Inteligencia operativa
- Dashboard ejecutivo
- Alertas automáticas
- Pronóstico básico de demanda
- Recomendaciones de reabasto

## Criterios de aceptación transversales
- Control de permisos por endpoint y pantalla
- Trazabilidad de cambios crítica (auditoría)
- Reportes exportables (CSV/Excel)
- Latencia objetivo en consultas críticas menor a 2 segundos
